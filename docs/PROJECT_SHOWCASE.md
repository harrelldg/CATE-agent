# CATE Project Showcase

CATE is a team-built AI voice booking manager developed for Cathay's Premium Travel challenge. The team advanced to the 24-hour Cathay Hackathon On-day among the top 5% of participating teams.

## Product

An Amazon Nova 2 Sonic speech-to-speech agent on AWS Bedrock orchestrates 16 rule-enforced tools for verification, booking, and payment across 16,823 real Cathay flights. Safety controls include one-time-code verification and human-confirmed holds. Accessible trip pages support both tap and voice interaction.

## Technical evidence

The repository contains the application source, environment template, contracts, tests, and technical documentation. Setup and architecture details are in the main README. Credentials are not included and must be supplied locally through environment variables.

The test suite was run during portfolio preparation: 130 tests, 127 passed, 3 optional demo tests skipped, and 0 failed.
